chess online:
  front end
1. main screen - home, your avatar, nickname, country’s flag, status online, when joined, the friends button. 
2. Then under - The list of curent games. The list is tilenails with opponent’s name, avatar, when the game started. A single tailnails displays the current state of a particular game. By clicking on a game tilenail the screen with the game shows up.
3. a game screen displays gameboard with the current game state. Your opponent avatar, nickname, flag and the pieces captured above the board, yours under. At the very top of the screen a history line of the moves were made. At the very buttom - horizontal menu bar with the following buttons: resign(must be confirmed), draw(must be confirmed), chat(just a button, no implementation for now), prev and next move buttons for traversing throught the history of the current game.
4. Under the tilenails is a list of recent games with the show more button for lazy loading. 
  
server side events for everything, no sockets. Mysql for now.
